# Delivery MHS

Protótipo de delivery multi-tenant com dados fictícios. Node.js 24 recomendado.

```sh
npm ci
npm run dev
```

Abrir http://127.0.0.1:3000/loja/mhs-mercado.

```sh
npm run typecheck
npm run lint
npm run build
```

Plano de branches e correções em [docs/PLANO.md](docs/PLANO.md). Limites e próximos requisitos em [docs/SEGURANCA.md](docs/SEGURANCA.md).
